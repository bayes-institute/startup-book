## Overview

*Building What Lasts* is an operating manual, decision-making framework, and formal treatise on entrepreneurship, strategic positioning, organizational design, capital allocation, and long-horizon institutional evolution. Grounded in first principles, microeconomic theory, cognitive science, and financial forensics, it bridges the journey from landing the first customer to building a centuries-long self-sustaining institution.

Throughout all 36 chapters, the theoretical frameworks are grounded by a single evolving continuing case study: **Bayes Institute**—a world-class STEM education and research institution.

---

## Standardized Chapter Structure

To ensure consistency, pedagogical rigor, and quick reference utility, every chapter implements a standardized nine-section anatomy:

1. **The Central Question:** Why does this topic matter to a founder?
2. **The Theory:** Economics, psychology, empirical research, causal reasoning, and first principles.
3. **The Mental Models:** Equations, diagrams, frameworks, and decision procedures.
4. **The Industry Lenses:** How the theory operates differently across business models (Software/SaaS, Services/Consulting, High-Capex, and Education).
5. **The Limits and Counterexamples:** Failure modes, trade-offs, survivorship bias, and boundaries of applicability.
6. **The Practical Method:** A repeatable, step-by-step procedure for making an actual strategic decision.
7. **Case Study (Bayes Institute):** Chronological, concrete application to the same evolving institution.
8. **The Founder's Workbook:** Actionable worksheets, calculation templates, diagnostic matrices, and measurable outputs.
9. **Research Notes and Evidence:** Academic sources, empirical datasets, evidence quality ratings, and unresolved questions.

## Build System & Modular Workflow

The handbook compiles via XeLaTeX using the self-contained `theme/bayesstacknotes.sty` and local font assets.

### Windows: Build with Tectonic in PowerShell

Run the following commands from the repository root in PowerShell. This route
does not require Make, Bash, Perl, or a separate MiKTeX/TeX Live installation.
The bundled `fonts/` directory supplies the book's Inter and Outfit typefaces.

Download and extract the Windows x64 release of
[Tectonic](https://github.com/tectonic-typesetting/tectonic/releases/tag/tectonic%400.17.0)
(version 0.17.0 was used to verify this build):

```powershell
$ErrorActionPreference = 'Stop'
$version = '0.17.0'
New-Item -ItemType Directory -Path build/tools -Force | Out-Null
$downloadUrl = "https://github.com/tectonic-typesetting/tectonic/releases/download/tectonic%40$version/tectonic-$version-x86_64-pc-windows-msvc.zip"
Invoke-WebRequest -UseBasicParsing -Uri $downloadUrl -OutFile build/tools/tectonic.zip
Expand-Archive -LiteralPath build/tools/tectonic.zip -DestinationPath build/tools/tectonic -Force
```

Compile the full book:

```powershell
& './build/tools/tectonic/tectonic.exe' --keep-logs --keep-intermediates --outdir build startups-and-business-handbook.tex
if ($LASTEXITCODE -ne 0) { throw 'The book build failed; inspect the compiler output and build log.' }

# Open the compiled PDF.
Invoke-Item './build/startups-and-business-handbook.pdf'
```

Tectonic downloads LaTeX packages on the first run, so initial compilation
requires internet access and can take several minutes. It caches the packages
for subsequent builds and automatically reruns LaTeX to resolve the table of
contents and cross-references. The PDF is written to
`build/startups-and-business-handbook.pdf`, and the detailed log is at
`build/startups-and-business-handbook.log`. The `build/` directory, including
the portable compiler, is ignored by Git.

If Tectonic is already on your `PATH`, use `tectonic` in place of
`& './build/tools/tectonic/tectonic.exe'`. After setup, rerun only the compilation
command when editing the book. The Makefile commands below use Bash, `latexmk`,
and XeLaTeX; run them in an environment with those tools installed.

### 1. Rapid Single-Chapter Compilation
To iterate rapidly without compiling the entire book:
```bash
# Compile a specific chapter standalone (e.g. Chapter 4 -> build/chapters/chapter-04.pdf)
make chapter CH=4
# Or use shortcuts:
make ch4
make ch CH=1
```

### 2. Chapter Locking & Status
Once a chapter is reviewed and verified, lock it into the release catalog:
```bash
# Verify, compile, and lock Chapter 4 (saves release copy to build/locked/chapter-04.pdf)
make lock CH=4

# Check lock and draft status of all active chapters
make status

# Unlock a chapter if further edits are required
make unlock CH=4
```

### 3. Master Book & Batch Targets
```bash
# Compile all active chapters standalone into build/chapters/
make chapters

# Compile the entire master book (all chapters unified -> build/startups-and-business-handbook.pdf)
make pdf
# (or make book)

# Continuous watch-mode compiler (works for chapter or full book)
make watch CH=4
make watch

# Clean generated build artifacts
make clean
```
