# Local logo assets

`knowledge_logo.svg` is the Bayes Knowledge publisher lockup.
`emblem-primary.svg` is the B used as the cover watermark. Original paths and
proportions are preserved. The book's build prepares vector PDF derivatives
in this folder: primary, black, and (for the publisher lockup) reversed white.
The interior uses black; the cover uses the white lockup on burgundy.
These files and their source SVGs belong to this book; no parent assets are used.
