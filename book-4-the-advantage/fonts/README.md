# Bundled text fonts

- EB Garamond Regular 400 and SemiBold 600: reading text, titles, and emphasis.
- Inter Regular 400 and SemiBold 600: navigation, captions, and functional labels.

These four static font files are the only bundled text faces. They need no
system installation. Emphasis stays upright; no italic face is loaded. Standard
mathematical symbols are supplied by LaTeX's math packages.

The SIL Open Font Licenses are included as `EBGaramond-OFL.txt` and `Inter-OFL.txt`.
