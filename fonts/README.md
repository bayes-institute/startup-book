# Font sources

Only EB Garamond and Inter are retained. `static/` contains the four text faces
used in the books: EB Garamond Regular/SemiBold and Inter Regular/SemiBold.
The original EB Garamond variable/italic source files are retained as family
source material; the book layout uses upright faces only.

Each book has its own four static font files and both SIL Open Font Licenses.
Books do not read this directory or require system font installation. Math
symbols are provided by the normal LaTeX math packages.
